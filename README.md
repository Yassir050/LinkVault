CodeVault — Code Snippet Manager

CodeVault is a modern, mobile-first web application for saving, organizing, searching, and managing useful code snippets.

✨ Features

* Save code snippets
* Organize snippets by programming language
* Search snippets quickly
* Sort snippets by newest, oldest, or name
* Mark snippets as favorites
* Delete snippets
* Responsive design for mobile and desktop
* Dark mode
* Local data storage using localStorage
* Clean and modern developer-focused interface

🛠️ Technologies

* HTML5
* CSS3
* JavaScript
* LocalStorage
* Responsive Web Design

🚀 How to Use

1. Open index.html in a browser.
2. Click New Snippet.
3. Enter the snippet name, language, category, description, and code.
4. Click Save Snippet.
5. Use the search bar or language filters to find your snippets.

📱 Mobile Support

CodeVault is designed with a mobile-first approach and can be used directly from a smartphone browser.

💾 Data Storage

Snippets are stored locally in the browser using localStorage.

This means the data stays on the current browser/device and is not stored on a remote server.

🎯 Project Goal

The goal of CodeVault is to create a practical personal code library that helps developers store and quickly access reusable code.
